# 首页 `/`

## 范围与模式

单一页面，持久化首页。**Persuade** —— 访客要做决定并采取行动（联系）。

受众：中小企业决策者（主）、创业者与个人客户（次）。任务：判断这家公司能不能做自己的东西、靠不靠得住、出问题找不找得到人。行动：电话 / 微信 / 表单。

凭证 / 内容：`PRODUCT.md` 的 `## Evidence on Hand` —— 2 个真实案例、2 条真实客户评价、4 家真实合作伙伴。全部真实，可作信任背书。

约束：Next.js 14 静态导出；不新增 npm 依赖；保留暗黑/明亮双模式；WCAG AA；百度为主要流量来源，首屏不滚动需传达完「做什么 + 凭什么信」。

## 方向契约

**THESIS**
页面本身就是一份正式商业凭证。它拒绝本品类默认的那个排布：深色底 + 紫蓝渐变 + 发光边缘 + 居中大标题 + 四张等大服务卡 + logo 墙。

**OWN-WORLD**
票据棕红 `#8C3A1E` 占满整片地面，是材料而非点缀；纸白 `#FDFCF9` 是币面；抵扣联蓝 `#1B3A6B` 与监制章红 `#C0271A` 各有专属职能，不混用。墨黑 `#1C1A17` 为字。栏线系统：0.5px 细实线分栏、双线收口，**零圆角、零阴影、零渐变**。数字一律等宽表格数字；标题用宋体（中文有衬线），正文用黑体，小字用等宽。组件语言：字段（label + 值）、行项（序号 + 名称 + 数量 + 金额）、合计、印章。

**STORY**
访客理解：这家公司把交付当成一份可核验的凭证 —— 每一行都写明做什么、多少、谁负责。访客相信：账目式的东西不会说谎。访客行动：拨打热线或留下联系方式。

**FIRST VIEWPORT**
整屏一份票据，不是「票据样式的 hero」。顶部是购方栏（公司抬头 / 备案号 / 日期），通栏。中部是明细行项表，四项服务各占一行，列对齐、数字右对齐。右下方是合计区，用中文大写金额收口。主行动（立刻联系）落在「开票动作」位置 —— 监制章旁，是页面上唯一的高饱和红，也是唯一的按钮。票面密度高、留白少，靠栏线建立秩序而不是靠留白。

**FORM**
票据 / 收款凭证。在我按共鸣度排序的 7 个候选里列第 7。seed key `4d45f41c`。

被抬高的两处（来自判决为 competitive 与 declined 的挑战者）：
- 来自航空客票钱包：明细区采用多联结构，已完成的联次不消失，只被核销章覆盖。
- 来自装饰艺术影院门厅：整页由单一材料色域占满，拒绝把强调色撒在灰底上当装饰。

**FINISH**
unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
